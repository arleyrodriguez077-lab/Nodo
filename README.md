# Nodo: Comunidad de Apoyo y Co-regulación

Nodo es una red social minimalista diseñada específicamente para personas con procesos de psicosis. A diferencia de las redes sociales tradicionales, Nodo no busca la popularidad ni la adicción, sino la **co-regulación emocional** y el apoyo mutuo.

## Propósito
Crear un entorno digital donde el ritmo lo marca el usuario, no el algoritmo. Un espacio libre de juicios donde la convivencia se basa en la **justicia restaurativa** y no en la exclusión.

## Características Principales
- **Minimalismo Sensorial**: Interfaz diseñada para reducir la ansiedad.
- **Botón de Crisis**: Herramientas inmediatas de contención emocional.
- **Convivencia Restaurativa**: Sistema de "Tiempo de Recapacitación" para infractores, promoviendo la reflexión sobre el respeto.
- **Anonimato**: Acceso mediante identificadores únicos.

## Instalación
1. Clona el repositorio: `git clone [enlace-de-tu-repo]`
2. Instala dependencias: `npm install`
3. Inicia el servidor: `npm run dev`
